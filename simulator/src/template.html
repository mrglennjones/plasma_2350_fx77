The effects in eff.py are tuned for a strip that swaps red and green (e.g. set_rgb(i, g, r, b) or “hue 0.33 = red”). This setting only changes the display, not the values in the code.

Advanced

Time per write estimates how long one set_hsv or set_rgb call takes in MicroPython, including the loop. For effects without sleep it sets their speed.

Time is virtual: time.sleep advances it instantly and every LED write adds an estimated compute cost, so an effect runs at the speed it would on the board, not at the browser's speed. As in the firmware, the strip is sampled 60× a second, so a half-drawn frame shows up if an effect writes without pausing.

    
set_hsv and set_rgb follow ws2812.cpp from pimoroni-pico: values over 255 wrap around, a negative hue leaves the LED unchanged, set_rgb with a float raises TypeError, and writes past the end of the strip are reported as warnings. Python runs on Pyodide (CPython), so small differences from MicroPython are possible.
